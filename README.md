# Zodi Tools

Bibliothèque d'utilitaires et de scripts réutilisables pour l'écosystème Zodi AI.

## Périmètre
- Outils de diagnostic et de maintenance.
- Scripts d'automatisation réutilisables.
- Petits composants partagés entre les dépôts Zodi.
- Documentation d'utilisation et exemples sûrs.

## Règles
- Un outil doit avoir un objectif précis, des entrées/sorties documentées et des erreurs explicites.
- Éviter les actions destructives par défaut ; proposer un mode simulation lorsque pertinent.
- Ne pas intégrer de secrets ni de données personnelles.
- Ajouter des tests adaptés avant de déclarer un outil prêt à l'emploi.

## État initial
Dépôt documentaire initialisé. La pile technique et les conventions de tests seront choisies avec les premiers outils réels.
